# Audio-AI-Foundations-From-Wave-Physics-to-Transformers
A structured learning repository exploring the mathematics, signal processing, perception, and machine learning principles that power modern audio technology.


# Audio AI Foundations

A complete educational repository covering:

- Wave Physics
- Fourier Analysis
- FFT
- Sampling Theory
- STFT
- Spectrograms
- Mel Spectrograms
- MFCCs
- CNN Audio Models
- Audio Spectrogram Transformers (AST)
- Neural Audio Tokens
- Diffusion Audio Generation

## Learning Path

Wave Equation
→ Fourier Transform
→ FFT
→ Sampling Theory
→ STFT
→ Spectrograms
→ Mel Spectrograms
→ MFCCs
→ CNNs
→ Transformers
→ Audio Tokens
→ Diffusion Models
